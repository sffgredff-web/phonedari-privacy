1. 앱과 운영자

폰다리(PhoneDari)는 사용자가 승인한 같은 네트워크의 PC·태블릿 브라우저와 메모, 클립보드, 파일을 주고받는 앱입니다. 개인정보 문의: sffgredff@gmail.com

2. 데이터 처리 목적과 저장 위치

개발자는 앱 사용 중 메모·파일 등을 개발자 서버로 수집하지 않습니다. 회원가입, 광고, 분석·추적 SDK가 없습니다. 다만 사용자가 연결을 허용하면 아래 데이터가 휴대폰 밖의 승인된 브라우저로 전달됩니다. 이는 인터넷 서버를 거치지 않는 기기 간 전송입니다.

- 메모, 클립보드 기록, 선택한 파일 및 파일명: 저장·표시·동기화·전송을 위해 휴대폰 앱 전용 저장소에 보관하며, 승인된 브라우저에서 접근할 수 있습니다.

- 연결 기기 이름, 브라우저에서 생성한 기기 ID, IP 주소, 승인 토큰, 접속·만료 시각: 연결 승인과 접근 관리를 위해 휴대폰에 저장합니다.

- 6자리 접속 코드와 연결 허용 시간·앱 잠금 설정: 휴대폰에 저장합니다.

- PC 브라우저에는 재연결용 승인 토큰, 생성된 기기 ID 및 화면 설정이 localStorage에 저장됩니다. 공용 PC 모드는 토큰·기기 ID를 sessionStorage에 저장합니다. 이 ID는 IMEI 등 휴대폰 하드웨어 식별자가 아닙니다.

- PC 또는 휴대폰의 다운로드 폴더에 내보낸 파일과 사용자가 복사한 클립보드 내용은 해당 기기·앱에도 남을 수 있습니다.

3. 통신과 보안

휴대폰이 포트 8080의 서버를 실행하며 같은 와이파이·USB 테더링·핫스팟의 브라우저가 접속합니다. 새 연결은 6자리 코드 입력 후 휴대폰에서 허용해야 합니다. 유효한 승인 토큰이 있는 브라우저는 다시 승인하지 않고 재연결할 수 있습니다. 코드를 여러 번 틀리면 일시적으로 잠깁니다.

통신은 암호화되지 않은 HTTP입니다. 네트워크에서 통신을 관찰할 수 있는 사람이 코드·토큰·내용을 볼 위험이 있으므로 신뢰하는 개인 네트워크에서만 사용하고 공용 와이파이를 피하세요.

앱이 화면에 보이는 동안만 서버가 실행됩니다. 홈 이동·화면 잠금·파일 선택 중 중지되며 복귀하면 재연결합니다. 중단된 전송은 다시 시도해야 합니다.

4. 권한과 외부 앱

인터넷·네트워크·와이파이 상태 권한은 기기 간 연결에 사용합니다. 파일은 사용자가 시스템 선택창에서 고른 항목만 읽습니다. 앱 잠금은 Android 생체 인증·기기 인증을 사용하며 지문·얼굴 원본을 앱이 받거나 저장하지 않습니다. 포그라운드 서비스와 알림 권한은 사용하지 않습니다. 사용자가 다른 앱으로 파일을 열거나 내용을 공유하면 선택한 앱이 해당 데이터를 처리하며 그 앱의 정책이 적용됩니다.

5. 제공과 보관·삭제

개발자가 운영하는 외부 서버나 광고·분석 사업자에게 앱 사용 데이터를 보내지 않습니다. 사용자가 승인한 브라우저와 사용자가 선택한 외부 앱에만 기능 수행에 필요한 데이터를 전달합니다. 개발자가 수행하는 국외 이전은 없습니다.

휴대폰의 메모·클립보드·파일은 앱에서 삭제하거나 앱 데이터 삭제·앱 제거 시 지워집니다. 앱 전용 데이터는 Android 백업·기기 이전에서 제외하도록 설정했습니다.

승인 정보는 사용자가 연결을 취소하거나 코드를 변경하면 무효화되며, 정한 허용 기간이 지나면 만료됩니다. 제한 없음을 선택한 경우 취소할 때까지 유지됩니다. 공용 PC의 일회성 승인은 신호가 없는 상태가 3분을 넘으면 정리되며 최대 12시간 유지됩니다.

앱을 제거해도 PC 브라우저 저장값, 다운로드 사본, 다른 앱에 복사한 내용은 지워지지 않습니다. PC에서는 로그아웃하여 토큰을 지우고, 기기 ID·설정까지 지우려면 브라우저의 해당 사이트 데이터 삭제를 사용하세요. 다운로드 사본과 다른 앱의 내용은 해당 기기·앱에서 직접 삭제하세요.

6. 대상과 변경

폰다리는 아동을 대상으로 설계된 앱이 아닙니다. 오픈소스 고지는 앱의 연결 탭에서 확인할 수 있습니다. 방침이 바뀌면 본문과 시행일을 갱신합니다. 문의: sffgredff@gmail.com

English

PhoneDari connects your phone to browsers you approve on the same local network to exchange notes, clipboard text and files. Privacy contact: sffgredff@gmail.com.

The developer does not receive app usage content on developer servers. There are no accounts, advertising or analytics/tracking SDKs. Data does leave your phone when it is transferred to an approved browser.

The phone stores notes, clipboard history, selected files and filenames, approved device names, browser-generated device IDs, IP addresses, authorization tokens, connection/expiry times, the connection code and settings. Browsers store their token, generated device ID and display preferences in localStorage; public-PC mode uses sessionStorage for the token and device ID. These IDs are not hardware identifiers such as IMEI. Downloaded copies and copied clipboard text may remain on other devices or apps.

The phone runs a local server on port 8080. New connections require the 6-digit code and approval on the phone; browsers with a valid token can reconnect. Repeated incorrect codes cause a temporary lockout. Traffic uses unencrypted HTTP: someone able to observe the network may read codes, tokens or content. Use only trusted private networks and avoid public Wi-Fi.

Connections run only while the app is visible. Leaving the app, locking the screen or opening a file picker stops the server; returning reconnects approved devices. Interrupted transfers must be retried. Internet/network/Wi-Fi state permissions enable local connections. The app reads files you select with the system picker. App lock uses Android biometric/device authentication; the app does not receive or store fingerprint or face templates. No foreground service or notification permission is used.

No usage data is sent to developer, advertising or analytics servers. Data is transmitted to browsers you approve and external apps you choose for opening/sharing content. Those external apps apply their own policies. The developer does not transfer your data abroad.

Phone data remains until you delete it in the app, clear app data or uninstall. App-private data is configured to be excluded from Android backup/device transfer. Authorizations expire according to your chosen duration or are invalidated when revoked or the code changes; unlimited authorizations last until revoked. Public-PC authorizations are removed after over 3 minutes without activity and last at most 12 hours.

Uninstalling does not delete browser storage, downloads or content copied to other apps. Log out in the browser to remove its token; clear this site's browser data to remove its ID and preferences. Delete exported copies separately on each device or app.

The app is not designed for children. Open-source notices are available in the connection tab. Changes will be reflected in this policy and its effective date.
